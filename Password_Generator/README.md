# Password Generator 🔐

A Python-based Password Generator application that creates random passwords based on user preferences.

## Features
- Generate random passwords.
- Choose password length.
- Include uppercase letters.
- Include lowercase letters.
- Include numbers.
- Include special symbols.
- Copy generated passwords to the clipboard.
- Simple and user-friendly GUI.

## Technologies Used
- Python
- Tkinter
- Secrets
- String

## Project Versions
1. `password_generator.py` – Command-line version.
2. `password_generator_gui.py` – Graphical user interface version.

## How to Run

**GUI Version:**
```bash
python Password_Generator/password_generator_gui.py
```

**Command-Line Version:**
```bash
python Password_Generator/password_generator.py
```
