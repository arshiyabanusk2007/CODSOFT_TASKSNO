# Python To-Do List Application

## About the Project
A simple task management application developed using Python as part of the CodSoft Python Programming Internship.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Continuous menu options
- Input validation
- Error handling

## Technologies Used
- Python 3.14
- Visual Studio Code

## How to Run
1. Install Python.
2. Download the repository.
3. Open the To_Do_List folder in VS Code.
4. Run the command:

```bash
python todo.py
```

## Learning Outcomes
- Python lists and dictionaries
- While loops
- Conditional statements
- Functions and built-in methods
- Exception handling
